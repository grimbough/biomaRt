# Mapping of Ensembl versions to their release dates

Mapping of Ensembl versions to their release dates

## Usage

``` r
data(ensembl_versions)
```

## Format

A `data.frame` with two columns:

- `version`: Ensembl version (e.g., "v116")

- `release_date`: Release date of the Ensembl version (e.g., "June
  2026")
